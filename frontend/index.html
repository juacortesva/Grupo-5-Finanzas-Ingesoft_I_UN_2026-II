CT-06 — saveAnswer (PUT /api/surveys/{surveyId}/answers -> 204 No Content)

Reglas: BR-01..BR-03, validación en question_option, 404 si ajena/inexistente, 409 si COMPLETED, 422 si opción inválida.

Contrato CT-06 — Payload enviado:
{ "questionId": 1, "selectedOption": 1 }

Respuestas esperadas:
- 204 No Content (cuerpo vacío)
- 401: { "detail": "No autenticado" }
- 404: { "detail": "Encuesta no encontrada" }
- 409: { "detail": "La encuesta ya fue completada y no admite modificaciones" }
- 422 (dominio): { "detail": "Opción inválida para la pregunta seleccionada" }
- 422 (Pydantic): { "detail": [{ "type": "...", "loc": ["body", "..."], "msg": "..." }] }

CT-09 — completeSurvey (POST /api/surveys/{surveyId}/complete -> 200 OK)

Reglas: BR-03 (transición DRAFT -> COMPLETED), BR-04, BR-05, BR-06.

Contrato CT-09 — Respuesta 200 esperada:
{
  "surveyId": "UUID",
  "assignedCategory": "CONSERVATIVE | MODERATE | AGGRESSIVE | UNDER_EVALUATION",
  "evaluationStatus": "COMPLETED | ERROR",
  "totalScore": "string | null"
}
Errores esperados: 401, 404, 409 (si ya COMPLETED), 422 (si faltan obligatorias) con { "detail": "..." }.
